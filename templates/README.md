## 提交要求

- 每个模板一个文件，开头写清楚：用途、对应书中位置、填写耗时、适用人群
- 必须有一个**已填示例**（内容虚构并声明），再给空白模板
- 示例数据不要用真实公司、真实姓名、真实项目细节
- 文件名用小写英文 + 连字符：`project-card.md`、`offer-weights.csv`
- CSV 的说明行用 `#` 开头，避免导入表格时错列
